# UI Review Checklist

> 用法：评审时按顺序过，**阻断项不通过就不合并**。每项都写了验证方法，避免「我觉得没问题」。
> 核验日期：2026-11-14

## 阻断项（必须全部通过）

### 功能完整性

- [ ] 加载 / 空 / 错误 / 有内容 四态齐全 —— *逐个状态手动触发一遍*
- [ ] 空态有可执行的下一步动作 —— *看空态截图，是否有按钮或说明*
- [ ] 错误态可重试，文案用户能看懂 —— *断网后走一遍*
- [ ] 破坏性操作可撤销或有二次确认 —— *实际点一次删除*
- [ ] 返回键行为符合预期，不直接退出应用 —— *每个二级页面按一次返回*

### 系统集成

- [ ] edge-to-edge：内容不被状态栏 / 导航栏遮挡 —— *在带手势条和带三键导航的设备上各看一次*
- [ ] IME 弹出时输入框不被键盘遮住 —— *点开每个输入框*
- [ ] 横竖屏切换不丢状态、不崩 —— *旋转屏幕*
- [ ] 进程被杀后恢复到合理状态 —— *开发者选项「不保留活动」跑一遍*

### 无障碍

- [ ] 所有可交互元素触控目标 ≥ 48dp —— *开发者选项「显示布局边界」或 TalkBack 焦点框*
- [ ] 图标按钮有语义标签，装饰图 `contentDescription = null`
- [ ] TalkBack 遍历顺序符合视觉顺序 —— *开 TalkBack 从顶部滑到底部*
- [ ] 系统字体 200% 下无截断、无重叠 —— *设置里调最大字号*
- [ ] 状态不依赖颜色单独表达 —— *灰度截图看一眼*

### 主题

- [ ] 浅色与深色主题都正确（不是简单反相） —— *两套各截全屏*
- [ ] Dynamic color 关闭时 fallback 正常 —— *关闭系统主题色*
- [ ] 组件内无裸色值 / 裸字号 / 裸圆角 —— *搜 `Color(0x`、`fontSize =`、`RoundedCornerShape(`*

### 代码

- [ ] 依赖版本已从官方来源核验，非猜测
- [ ] API 稳定性已确认，`@OptIn` 均有原因注释
- [ ] 无不必要的 deprecated API
- [ ] 列表有 `key` 与 `contentType`
- [ ] 业务状态不在 Composable 内部持有

## 应修项（不阻断，但需记录）

### 设计一致性

- [ ] 信息层级清楚，一屏只有一个视觉最强点
- [ ] 主操作按钮样式唯一（Filled 强调只出现一次）
- [ ] 字号全部来自字阶，同屏字阶 ≤ 4 档
- [ ] 圆角全部来自档位，同屏档位 ≤ 3 种
- [ ] 间距成 4dp 体系
- [ ] 浮层用表面色阶表达层级，静止态卡片无大阴影
- [ ] 动效能说清目的（来自哪里 / 去了哪里 / 状态变了 / 注意力转移）

### 响应式

- [ ] 窄屏（< 600dp）内容不被挤压变形
- [ ] 宽屏（≥ 840dp）内容不拉成超长行，有最大宽度或双栏
- [ ] 折叠屏展开 / 折叠过渡不丢状态
- [ ] 弹出层不超出窗口边界

### 健壮性

- [ ] 超长文本（标题 2 行以上、标签 20 字）不撑破布局
- [ ] 0 条、1 条、1000 条数据都正常
- [ ] 图片加载失败有占位
- [ ] 弱网 / 慢速下加载态有反馈

## 建议项

- [ ] Preview 覆盖浅色 / 深色 / 大字号 / 空态
- [ ] 关键交互有语义驱动的 UI 测试
- [ ] 动画在低端机不掉帧（滚动列表时观察）
- [ ] 自定义组件有注释说明为何不用官方组件

## 评审结论模板

```
阻断项：X 项未过
应修项：X 项
结论：通过 / 有条件通过 / 打回
未过项清单：
1. [阻断] IME 遮挡 —— 输入框位于屏幕下半部时被键盘盖住
2. [应修] 深色主题下 secondaryContainer 上文字对比度不足
```

## 最容易漏的三项

1. **空态**。开发时数据永远是有值的，空态往往最后才被发现没做。
2. **200% 字体缩放**。固定高度容器一测就崩，但没人主动去调字号。
3. **深色主题下的层级**。阴影在深色下不可见，只靠 elevation 的层级全部消失。
