## 4. AI 使用建议

1. **默认忽略 2020-09 之前的实现类博文**（M2 主题教程、Material Motion for Android、MDC 迁移）。
2. 需要**版本 API 事实**时优先用 1.1 节（版本发布），并核对 `03-Android-Compose/platforms.md` 的终版/维护状态。

4. 引用任何博客前先确认它不在第 3 节；第 3 节列出的文章即使内容「看起来合理」也不得作为现行规范使用。
